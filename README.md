# 🤖 Door Escape Game

A fun and simple web game built with **HTML**, **CSS**, and **JavaScript**. The objective is straightforward — open the doors one by one, but **avoid the door hiding the robot!** If you open the robot door, it's game over. 🎮

---

## 🕹️ Gameplay

- There are **three doors** on the screen.
- Behind one of them is a **robot**.
- Your goal is to open all the doors **except** the one hiding the robot.
- If you open all the safe doors, **you win**.
- If you open the robot door — **game over!**

---

## 🚀 Features

- Simple and intuitive UI
- Pure HTML, CSS, and JavaScript — no frameworks required
- Lightweight and fast to load
- Randomized robot placement each round
- Playable in any modern web browser
